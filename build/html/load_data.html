load_data.initialize_npcs(name_npcs, types_npcs, quests, locations, phrases, items)¶

Initialize a list of NPCs, distributed across all locations.

Parameters:

  • num_npcs (int) – The total number of NPCs to create.

  • name_npcs (list) – List of names NPCs can have.

  • type_npcs (list) – List of types NPCs can have.

  • quests (dict) – Dictionary of quests that the NPCs can give.

  • locations (list) – List of location dictionaries that NPCs can be assigned to.

  • phrases (list) – List of phrases that NPCs can say.

  • items (list) – Items that are in NPC’s inventory.

Returns:

List of initialized NPC objects.

Return type:

list
